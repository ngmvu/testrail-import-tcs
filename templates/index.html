Excel Keyboard Shortcuts & Bullet Level Guide (Parent vs Child)

Rules to distinguish main parent bullets vs indented sub-bullets inside an Excel cell.

🎹 Step-by-step Excel keyboard shortcuts inside a cell:
  • • Line 1 (Parent item): Type - Main item 1 ➔ Press Alt + Enter for line break inside cell.
  • • Line 2 (Child item): Press Spacebar 2 times ➔ Type - Sub-item 1.1 ➔ Press Alt + Enter for line break.
  • • Line 3 (Child item): Press Spacebar 2 times ➔ Type - Sub-item 1.2 ➔ Press Alt + Enter for line break.
  • • Line 4 (Parent item): Type - Main item 2 (no leading space).
🎯 Core Hierarchy Rules:
• Parent Level (Main item): No leading space (- Item).
• Child Level (Indented): Add 2 leading spaces before dash (  - Sub-item).
🖥️ Output Rendering on TestRail:
• Main item 1
    • Sub-item 1.1
    • Sub-item 1.2
• Main item 2
